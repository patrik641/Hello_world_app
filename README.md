# Hello World aplikacija

## Opis aplikacije

Preprosta Android aplikacija, izdelana v Android Studiu.

## Odgovori na vprašanja

### 1. Katera datoteka vsebuje programsko logiko glavne aktivnosti?

Programsko logiko glavne aktivnosti vsebuje datoteka MainActivity.java.

### 2. Katera datoteka določa postavitev uporabniškega vmesnika?

Postavitev uporabniškega vmesnika določa datoteka activity_main.xml.

### 3. Zakaj je priporočljivo besedila hraniti v datoteki strings.xml?

Ker lahko besedila lažje spreminjamo in prevajamo v različne jezike. Tako je koda bolj urejena.

### 4. Kaj je namen omejitev (constraints) pri postavitvi ConstraintLayout?

Constraints določajo položaj in velikost elementov.

### 5. Kakšna je razlika med delom v pogledu Design in delom neposredno v XML?

V pogledu Design elemente dodajamo in urejamo grafično z povleci in spusti. V XML pa uporabniški vmesnik urejamo neposredno s pisanjem kode.
