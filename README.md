# Hello World aplikacija

## Opis aplikacije

Preprosta Android aplikacija, izdelana v Android Studiu. Aplikacija uporabniku prikazuje sporočila na dva načina: s **Toast** obvestilom, ki se za kratek čas pojavi na dnu zaslona in nato samo izgine, ter s **Snackbar** obvestilom, ki se prikaže na dnu zaslona in lahko vsebuje tudi gumb za dodatno dejanje. Namen aplikacije je spoznati osnove razvoja Android aplikacij.
